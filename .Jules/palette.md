## 2024-11-03 - In-Context Status and Dimension Presets in Terminal CLI

**Learning:** In CLI utilities where users enter numeric geometry values (like window width/height), revealing current dimensions and standard resolution references before user input prevents cognitive load and errors, compared to displaying current geometry only after user submission.
**Action:** When designing terminal configuration prompts, display current entity state (e.g., current width x height) and helpful reference presets inside the input frame rather than after inputs are submitted.
